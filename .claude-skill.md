# stash Skill

Use this skill to interact with Bitbucket Server (Stash) via MCP tools.

## When to Use

- Discover available Bitbucket projects and repositories
- Review pull requests and diffs
- Add comments or merge/decline pull requests
- Search code across repositories

## Authentication Check

Before using any stash tools, verify authentication by calling a safe tool:

```typescript
const authCheck = await mcp.callTool('stash', 'list_projects', {});

if (authCheck.isError) {
  return {
    error: 'Authentication required',
    message: 'Configure credentials in ~/.claude/user-mcps.json',
    setup: [
      'Set BITBUCKET_URL to your Stash/Bitbucket Server base URL',
      'Set BITBUCKET_TOKEN (or BITBUCKET_USERNAME/BITBUCKET_PASSWORD)',
      'Restart Claude to load updated MCP config'
    ]
  };
}
```

## Available Tools

- `list_projects`, `list_repositories`
- `get_pull_request`, `get_diff`, `get_reviews`, `get_activities`, `get_comments`
- `create_pull_request`, `merge_pull_request`, `decline_pull_request`
- `add_comment`, `add_comment_inline`
- `search`, `browse_repository`, `get_file_content`

## Examples

### List repositories in a project
```
list_repositories:
  project: PROJ
  limit: 25
```

### Review a pull request
```
get_pull_request:
  project: PROJ
  repository: my-repo
  prId: 123
```

### Search for a filename
```
search:
  query: README.md
  type: file
  project: PROJ
```

## Troubleshooting

**Authentication Errors**
- Verify credentials in `~/.claude/user-mcps.json`
- Confirm the token is valid and has API permissions
- Restart Claude after configuration changes

**API Errors**
- Check the Bitbucket Server base URL
- Ensure the REST API endpoints are reachable
- Some instances disable search API; if so, avoid `search`

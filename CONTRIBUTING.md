# Contributing

Thanks for your interest in contributing.

## Development

1. Fork and clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Run the build and tests:

```bash
npm run build
npm test
```

## Pull Requests

- Keep changes focused and well-scoped.
- Include tests for behavior changes when feasible.
- Update documentation if you change any public behavior.

## Issues

Use GitHub Issues to report bugs or request features. Include steps to reproduce, expected behavior, and actual behavior when possible.
